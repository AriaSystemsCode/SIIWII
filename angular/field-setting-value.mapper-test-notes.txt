Mapper elements and required inputs
===================================

Mapper functions:
  fieldSettingValuesToAppEntityExtraData: field settings -> extra-data rows
  appEntityExtraDataToFieldSettingValues: extra-data rows -> field settings
  dynamicSelectionsToAppEntityExtraData: dynamic component change event -> extra-data rows
  appEntityExtraDataToSelectedValues: extra-data rows -> one control's selected value(s)

Required data for a meaningful mapping:
  FieldSettingValueDto.settingFieldId: identifies the setting field; required.
  FieldSettingValueDto.value: setting value as a string; may be empty/undefined.
  AppEntityExtraDataDto.attributeId: maps to settingFieldId; required.
  AppEntityExtraDataDto.attributeValue: maps to value; may be empty/undefined.
  DynamicFieldSettingSelection.attributeId and value: required event properties.
  ExtraAttribute.attributeId: required to match a setting to its definition.
  ExtraAttribute.acceptMultipleValues: needed to preserve multi-select values.
  ExtraAttribute.isLookup: needed to interpret a numeric value as attributeValueId.
  ExtraAttribute.dataType: needed to display numeric and date values with the correct control type.

Optional/context data:
  FieldSettingValueDto.settingFieldCode and settingFieldName: descriptive metadata.
  AppEntityExtraDataDto.attributeCode and attributeValueId: code and lookup ID when available.
  ExtraAttribute.code and name: used to fill descriptive metadata when supplied.
  entityId: optional mapper argument; defaults to 0 for Field Manager dynamic controls.
  AppEntityExtraDataDto.id: set to 0 because these mapped rows are not persisted entity extra-data records.

Core field mapping:
  settingFieldId <-> attributeId
  value <-> attributeValue (or attributeValueId converted to a string when no text value exists)
  settingFieldCode <-> attributeCode
  Multiple selected values <-> multiple rows with the same settingFieldId/attributeId
